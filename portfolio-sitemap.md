# Sitemap — El Novato Automotriz / Ian's Portfolio

## Proof statement (fill in)

**Claim (skill I'm proving):**
> I can build production-ready full-stack applications, with real security (OWASP) and complex integrations.

**Who I'm proving it to (target person):**
> Technical recruiters / tech leads evaluating my profile for Full Stack / Backend roles.

**Single action I want them to take:**
> Contact me for an interview.

---

## Sitemap (4 pages)

```
        [HOME]
          |
   -------|-------
   |             |
[WORK]      [ABOUT]
   |             |
   -------|-------
          |
     [CONTACT]
```

### 1. Home — The proposition
**Page goal:** in 5 seconds, the visitor understands who you are and what you're claiming.

- [ ] Headline: who you are + core claim (1 line)
- [ ] 1 featured project with an impact metric (e.g. "20k lines, 36 endpoints, OWASP Top 10 covered")
- [ ] One clear, visible CTA ("View the project" / "Contact me")
- [ ] Nothing else: no carousel of side projects, no blog, no "services" section

**Why it earns its place:** without this, no one reaches the other pages.

---

### 2. Work / Case study — The evidence
**Page goal:** prove the claim with one real case, not a list of projects.

- [ ] El Novato Automotriz as the single case (not a grid of mini-projects)
- [ ] Structure: Real problem → Technical decisions → Result
- [ ] Screenshots: dashboard, WhatsApp bot, appointment system
- [ ] Concrete metrics (tests, endpoints, integrations)
- [ ] Avoid: presenting Naranja X and Sip Tracking as formal work experience

**Why it earns its place:** it's the concrete proof; without it, the claim is just text.

---

### 3. About — The trust
**Page goal:** show there's a serious, consistent person behind the code.

- [ ] Stack: Node.js, TypeScript, NestJS, React, PostgreSQL, AWS
- [ ] 2 years of real experience + FlyRank AI
- [ ] Why security / production-grade code matters to you (your differentiator)
- [ ] Max 3-4 paragraphs — not a full CV

**Why it earns its place:** builds trust, but only if kept short.

---

### 4. Contact — The action
**Page goal:** make the single requested action easy to take.

- [ ] One contact path only (email or LinkedIn)
- [ ] Link to CV (optional)
- [ ] No long forms or multiple action options

**Why it earns its place:** it's where the action you defined actually happens.

---

## Approval checklist

- [ ] The sitemap is small (4 pages, no more)
- [ ] Each page is justified in relation to the claim and the action
- [ ] No pages exist "just because" without real necessity
